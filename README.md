Developed a full-stack blog website using the MERN stack (MongoDB, Express.js, React.js, Node.js) with secure user authentication implemented using JSON Web Tokens (JWT) and Google OAuth. The platform supports role-based access control with two roles: Admin and User. Designed and integrated CRUD functionalities, allowing Users to read and comment on posts, while enabling Admins to add, update, and manage posts, delete users, and remove inappropriate comments to maintain platform integrity. Leveraged Redux Toolkit for efficient state management, optimizing application performance and delivering a seamless user experience. Built and deployed RESTful APIs using Express.js and Node.js for server-side logic, with MongoDB serving as the database for flexible and scalable data storage.
